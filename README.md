## 系统概述


家政公共服务平台通过整合业主管理、家政企业管理、订单管理、优惠券管理、技能竞赛、工种管理、证书管理、意见反馈等多项功能，实现家政服务的高效管理和精准对接，提升服务质量和用户体验
本项目名称为家政行业公共服务云平台，旨在为家政行业提供全方位的服务和管理，涵盖业主、家政企业、家政人员、技能竞赛、订单管理、投诉调解、系统管理等多个方面。该平台提供管理端系统、H5页面以及潜在的APP应用（根据文档内容推测），实现了从用户注册登录、服务下单、订单管理到投诉处理、数据分析等完整业务流程管理。平台致力于提高家政行业的服务效率和管理水平，促进家政行业的规范化和健康发展。

本项目从用户层面至少可以分为两个端：管理端系统和H5页面端。
- 管理端系统：面向平台管理员、家政企业、家政人员等用户，提供全面的管理功能，例如业主管理、医无忧管理、家政企业管理、技能竞赛管理、订单管理、系统管理等。
- H5页面端：面向业主用户，提供服务浏览、下单、订单管理、评价、投诉等功能。

## 系统功能说明

核心功能：
- 业主管理：管理业主信息，提供便捷的服务入口。
- 医无忧：提供医疗陪护服务，包含轮播管理、项目展示、人员管理、积分管理等功能。
- 家政企业管理：管理家政企业信息，包含评级排行、车辆信息、业主列表等。
- 家政人员管理：管理家政人员信息，包含考勤、健康日志、业绩统计等。
- 订单管理：管理订单流程，包含投诉列表、自助下单、订单列表、评价管理等。
- 系统管理：提供系统级别的管理功能，包含用户管理、角色管理、菜单管理等。
- H5功能：提供面向用户的移动端服务，包含首页服务展示、下单、订单管理、个人中心等功能。
